# بوت التحكم المستقل — ماستر الغرفة واللغة

## نظام اللغة
بعد نجاح أول إضافة لبوت إلى غرفة، يرسل بوت التحكم للشخص الذي أضافه رسالة خاصة:

1️⃣ العربية
2️⃣ English

أرسل 1 أو 2، ثم أرسل `help` لعرض الأوامر باللغة المختارة.

لغة كل غرفة محفوظة بشكل مستقل. ويمكن للماستر تغييرها لاحقاً:
- `lang@ar`
- `lang@en`
- إذا كان الماستر يدير عدة غرف: `lang@ar@اسم_الغرفة` أو `lang@en@اسم_الغرفة`

## المتغيرات
- CONTROL_BOT_USERNAME
- CONTROL_BOT_PASSWORD
- SERVER_URL
- SERVER_KEY
- CONTROL_LANGUAGE
- ROOM_PASSWORD
- CONTROL_POLL_SECONDS

## صلاحيات الإضافة
لا يتم اعتماد البوت في الغرفة إلا إذا كانت رتبته `moderator` أو `admin`. إذا كانت رتبته عضوًا عادياً يتم رفضه وإخراجه.

أول شخص ينجح في إضافة أول بوت للغرفة يصبح الماستر الأساسي تلقائياً، ثم يستطيع إضافة ماسترات مساعدين.
